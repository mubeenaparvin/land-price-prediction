# Land Price Prediction

Predicts the price of a plot of land from its size (square feet)
using Linear Regression.

## What this project covers
- Difference between regression (predicts a number) and classification (predicts a category)
- Visualising the relationship between land size and price with a scatter plot
- Training a Linear Regression model with scikit-learn
- Predicting the price for a new plot size
- Drawing the best-fit line over the data
- Verifying the model by hand using `y = m*x + b` (slope and intercept)

## Tech stack
Python, pandas, NumPy, matplotlib, scikit-learn

## Dataset
A small dataset of 10 plots with two columns: `land` (size in square feet)
and `price`. Place `landpriceprediction.csv` in a `data/` folder to run the notebook.

## How to run
1. Clone the repo: `git clone https://github.com/mubeenaparvin/land-price-prediction.git`
2. Install dependencies: `pip install pandas numpy matplotlib scikit-learn jupyter`
3. Open `03_land_price_prediction.ipynb` in Jupyter and run all cells.
